# K4-7 (major) — control 7 (list seed 42->43) is invisible to three of the four drivers and to any run with samples=0

Artefact: `results/recreate-code-plan.md` §6 item 7 ("reservoir-sampling seed
42 -> 43 in `list` (must move `ub` output, must not move the recorded run)");
sources seed.cpp:97-115, ub.cpp:369-386, patchx.cpp:455-458, and the guard lines
atlas.cpp:216, stageB.cpp:283, stageC.cpp:533, covout.cpp:1.

(a) Dead in the recorded run — free. `seeds::list` is called only from the three
guarded `main`s (seed.cpp:118, ub.cpp:372, patchx.cpp:457). covrun defines
HEADER, arun defines PATCH_HEADER and hence UB_HEADER, brun defines
ATLAS_HEADER, crun defines REFINE_HEADER, so all three mains are compiled out of
every built binary. "Must not move the recorded run" needs no test.

(b) The other half is conditional and weakly observable.
 * `rng()` is drawn only in `else if(samples>0){ j=rng()%m; ... }` (seed.cpp:108).
   `seed`'s own driver calls `list(0)` (seed.cpp:118), so 42->43 changes nothing
   there — not even the printed `out` field.
 * `list` itself prints only counts ("... share %lu out %zu"); the sampled pairs
   are not printed, so that line is seed-invariant at every n.
 * only the drivers that call `list(samples>=1)` see the seed, and only if more
   than `samples` pairs survive (`m` = the "share" field).
 * ub's stdout is a 10-decile vector of `Q.prev.size()` over the sampled cells; a
   coarse statistic, which can coincide.

Measured on a copy (n=12, samples=3, samples m=34,782 so the reservoir is active):
  ./ub 12 3 .032 3 2 0 1 with rng(42) vs rng(43) -> outputs differ, but the
  `list` line ("12 xs197 avg y 199.1 counts gap 38368 share 34782 out 3") is
  identical in both, and only the Usearch report lines move;
  ./ub 12 0 .032 3 2 0 1 -> byte-identical under both seeds.
(`g++ -O2 -ffp-contract=off ub.cpp -o ub` builds: ub.cpp is a complete program,
its own main being behind `#ifndef UB_HEADER`.)

Consequences for V: a harness that builds only the four TUs passes control 7 while
testing nothing (spec §2 even says to build the extra drivers only if a unit test
needs them), and a harness that runs `ub` with samples=0 also passes while
testing nothing. Missing the mutation is the default outcome.
Recommendation: move control 7 to R1 as an API test — call `seeds::build(n)` and
`list(1000)` twice with the seed patched and require the returned vectors to
differ — and keep "recorded run unchanged" as the R2-R6 half, where it is free.
