# K2-4 — two replay-loop traps that are not about any single artefact

Team K, member m2, direction k2. Continuation of `K2-1.md`/`K2-2.md`.

---

## H-11 (major) — a comparator that discovers its file list from *our* output cannot notice a missing file

`for f in "$R"/batches/f*.bin; do cmp "$f" "$CACHE/…/$(basename "$f")"; done` compares only the
files our run happened to produce. A run that emits 87 of 88 batches passes; so does one that
emits a batch under a name nobody expects. The same shape appears at R6 if the driver walks the
produced tree instead of `commands.json`, and at R5 for `fdone.txt` (recorded `88 22379`).

**Settling test.** `work/10-recreate/crew/m2/globdemo/`: with one of eight batch files removed,
the glob-driven comparator prints `files compared: 7, verdict: PASS`; the record-driven
comparator prints `DIFF f85.bin, verdict: FAIL`.

**Guard (V).** take the expected file list from the record — `commands.json` `outputs` (107
paths) plus the 88 `batches/f<i>.bin` and `batches/fdone.txt` implied by the `Bfine` prefix and
the `"88 22379"` in `fdone.txt`; require each to exist and match, and require the produced
`batches/` to contain exactly 88 `f*.bin` (no extras). The recorded data tree has exactly 196
files = 107 + 88 + 1; anything else in our tree is a deviation to report, not to skip.

## H-12 (minor) — 15 of the 100 commands return 1 by design; `set -e` stops the replay at the third one

Recorded return codes: 85 × 0, 15 × 1 (`C.batch3,4,5,6,7,8,10,52,53,55,56,78,79,80,84`). A replay
loop under `set -e` (or a driver that treats nonzero as failure) aborts at `C.batch3`, i.e. at
command 8 of 100, and reports the *code* as broken. The mirror error — `|| true` everywhere —
loses the rc check that R6 exists to make.

**Settling test.** `( set -e; false; echo reached )` prints nothing and returns 1.

**Guard (V).** the driver takes the expected rc from `commands.json` per key, compares it, and
continues; rc mismatch is a FAIL of that command, not an abort. `logs/R6.json` records
`key, argv, expected_rc, actual_rc, stdout_path, outputs[]` for all 100.
