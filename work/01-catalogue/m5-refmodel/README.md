# m5-refmodel

Executable reference model for the analytic core of the preprint (direction d3 of
swarm smwgrqhwo). See `REPORT.md` for results and findings.

    python3 run_checks.py     # 30 checks, ~6 s, deterministic; writes checks.json

Files: `mubref.py` (implementation, one function per numbered statement),
`run_checks.py` (the checks), `checks.json` (last run), `stageA_sweep.py`
(standalone 400-seed Stage-A sweep), `REPORT.md` (findings F1-F5).
